Uppercase, letter-spaced CTA — primary navy for the main action ("Angebot anfragen"), outline for the secondary, link for in-card "Mehr erfahren".
```jsx
<Button icon="arrow-right">Angebot anfragen</Button>
<Button variant="outline">Leistungen ansehen</Button>
<Button variant="link" icon="arrow-right">Mehr erfahren</Button>
```
- On dark heroes pair `accent` (signal blue) with `outline-light`.
- Always pair max two buttons; primary first.
